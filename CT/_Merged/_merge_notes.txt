CT MERGED TEMPLATES — how to read these
- One file per study. The base is the most common plain version; other versions were folded in.
- 'ALT:' lines sit under the line they replace — keep one wording, delete the other.
- Lines only in other plain versions were inserted where they appeared.
- Site-specific (S / P style) lines are grouped in a marked block at the end of Content — delete the block if you don't use that style.
- EXAM line uses [with/without] contrast. Hardcoded DLP values were replaced with [].
- Prompt = de-duplicated union of all versions' instructions; conflicts are flagged below.
